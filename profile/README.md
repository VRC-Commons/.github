### 把共同的想法，做成大家能用的东西。

**VRC Commons 是一个社区共建计划。** 围绕社区的实际需求，一起完善工具、体验和协作方式。你可以从一个反馈、一段说明或一次改进开始参与。

## 当前项目

### vrcfun账号系统

面向社区应用的账号与身份管理服务，提供登录注册、个人资料、会话管理与应用接入等功能。

[访问账号系统](https://accounts.nyanote.cn) · [提交问题与建议](https://github.com/VRC-Commons/identity-feedback/issues/new/choose) · [查看处理进度](https://github.com/orgs/VRC-Commons/projects/1)

| 公开入口 | 可以做什么 |
| --- | --- |
| [用户反馈](https://github.com/VRC-Commons/identity-feedback) | 报告可复现的问题、提出功能建议、交流一般使用方式。 |
| [处理看板](https://github.com/orgs/VRC-Commons/projects/1) | 了解反馈的分诊、处理、验证和版本计划。 |

## 一起参与

- **发现问题**：说明复现步骤、预期结果和实际表现，帮助维护者定位问题。
- **提出建议**：从使用场景出发，讲清希望解决什么问题，以及现有方式哪里不方便。
- **完善内容**：欢迎通过 Pull Request 改进公开仓库中的说明、反馈模板和协作内容。

项目是否开放源码，以各项目的说明为准。欢迎参与公开反馈，不需要获得源码仓库的访问权限。

## 反馈与安全

提交前请先搜索相同问题。公开 Issue、评论和附件中不要填写密码、验证码、Cookie、Token、个人账号资料或未脱敏的完整日志。

涉及 vrcfun账号系统的安全漏洞或隐私泄露，请使用[私密安全报告](https://github.com/VRC-Commons/identity-feedback/security/advisories/new)。账号申诉、身份核验与找回账号请通过产品明确提供的官方途径联系维护者。
